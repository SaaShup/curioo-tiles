Welcome to Tile Editor

This server generates PNG map tiles for Map Game Explorer (CuriooCity). It provides configured zoom-range tiles with cached Overpass-based map features.

Tile API

GET
/{z}/{x}/{y}.png
Default theme tile endpoint. Supported zooms are controlled by TILE_ZOOM_RANGE. 
GET /18/135329/89901.png
GET
/{theme}/{z}/{x}/{y}.png
Generate themed tiles using the selected map style. 
      GET /forest/18/135329/89901.png
      GET /city/18/135329/89901.png
      GET /space/18/135329/89901.png

Editor API

GET
/api/themes
Retrieve all available themes. 
GET /api/themes
PUT
/api/themes/{theme}
Save a theme configuration (protected endpoint). 
PUT /api/themes/forest
POST
/api/preview-theme/{theme}
Apply a temporary preview theme without saving it. 
POST /api/preview-theme/forest
DELETE
/api/preview-theme/{theme}
Clear the temporary preview theme cache. 
DELETE /api/preview-theme/forest

Monitoring

GET
/healthz
Health check endpoint. Returns a simple JSON response when the service is running. 
GET /healthz
Response: { "ok": true }
GET
/metrics
Prometheus metrics endpoint. Exposes default Node.js metrics and CuriooCity tile metrics. 
GET /metrics

Service API

GET
/api/version
Returns the application version from package.json. 
GET /api/version
Response: { "version": "x.y.z" }
GET
/api/config
Returns public runtime configuration, including the active tile zoom range. 
GET /api/config
Response: { "tileZoomRange": [18, 18] }

Auth API

GET
/api/login
Login route for protected editor actions using Keycloak. 
GET /api/login
GET
/api/logout
Logout route for clearing the editor session and returning the user to a public page. 
GET /api/logout
