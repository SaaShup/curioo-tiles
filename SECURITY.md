# Security Policy

## Supported Versions

The latest version of Curioo Tiles is currently supported with security updates.

| Version | Supported |
| ------- | ---------- |
| latest  | ✅ |

## Reporting a Vulnerability

If you discover a security vulnerability, please do not open a public issue.

Instead, contact the maintainer privately:

- GitHub: https://github.com/SaaShup
- Email: contact@saashup.com

Please include:

- Description of the issue
- Steps to reproduce
- Potential impact
- Suggested fix (if available)

We will try to respond as quickly as possible.
