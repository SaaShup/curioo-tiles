# Contributor Covenant Code of Conduct

## Our Pledge

We as contributors and maintainers pledge to make participation in this project a harassment-free experience for everyone.

## Our Standards

Examples of behavior that contributes to a positive environment include:

- Being respectful and constructive
- Accepting feedback gracefully
- Helping other contributors
- Focusing on what is best for the community

Examples of unacceptable behavior include:

- Harassment or insulting comments
- Trolling or personal attacks
- Publishing private information
- Any other inappropriate conduct

## Enforcement Responsibilities

Project maintainers are responsible for clarifying and enforcing standards of acceptable behavior.

## Scope

This Code of Conduct applies within all project spaces, including:

- GitHub issues
- Pull requests
- Discussions
- Community spaces

## Reporting

If you experience or witness unacceptable behavior, contact:

- https://github.com/SaaShup
- contact@saashup.com

All reports will be reviewed and investigated promptly.
